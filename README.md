# Resident Access 0

A screen reader mod that will make **Resident Evil 0 HD Remaster** (Steam, PC) playable blind with an Xbox controller. It speaks through your screen reader (NVDA, JAWS and others), or Windows' own voice.

It is built from [Resident Access HD](https://github.com/RetroSanity/Resident-Access-HD), the mod for Resident Evil HD Remaster.

## Status

Early development. Download the latest version from the [Releases page](../../releases/latest), unzip it and run Install Resident Access 0.bat. What works so far:

- Finds the game and says when it is ready.
- Says which room you are in as you move between rooms.
- Makes the controller add-on work with Steam Input, so the mod can press buttons for you (needed for auto walk).

Coming next: health and items, reading the game's messages and menus, the room list (doors, items, things to check, puzzles, enemies), auto walk and the 3D beacon, and Rebecca and Billy's partner features.

## What you will need

- Resident Evil 0 / biohazard 0 HD REMASTER on Steam, on Windows 10 or 11
- A screen reader (or Windows' own voice)
- An Xbox controller
